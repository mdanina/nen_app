# books:enrich

Повторно используемый инструмент обогащения книжного каталога объективными данными современных изданий. Он сопоставляет произведение по названию и автору, последовательно опрашивает подключённые источники и выбирает наиболее новое российское издание.

## Запуск

```bash
pnpm books:enrich:dry-run
pnpm books:enrich:audit
pnpm books:enrich
```

Для контролируемого запуска доступны `--limit=N`, `--book-id=ID`, `--sources=source-a,source-b`, `--concurrency=N`, `--force` и `--no-build`.

Инструмент обновляет только ISBN, издательство, год, страницы, серию, язык и подтверждённую официальную обложку. ID, slug, описания, рекомендации, возраст, жанры, темы, настроение и подборки защищены от изменений.

## Источники и результат

Адаптеры находятся в `sources/` и реализуют метод `findEditions(book)`. Сейчас подключены официальные каталоги издательств, Google Books и Open Library; ошибка одного источника не останавливает обработку книги или каталога.

Подтверждённые изменения сохраняются через существующие файлы overrides. Итоговый отчёт записывается в `data/reports/books-enrichment.json`, а повторно используемый сетевой кеш — в игнорируемый каталог `data/.cache/books-enrich/`.

Повторный запуск пропускает недавно проверенные актуальные карточки. Перед записью инструмент проверяет неизменность редакционных полей, уникальность ID и slug, отсутствие дублей, обязательные поля, ISBN и ссылки на официальные обложки.

`books:enrich:audit` выполняет только локальный пересчёт статусов и не обращается к внешним источникам. Карточка получает `already_current` только при наличии свежего пакета доказательств версии инструмента: совпадения произведения и автора, точного ISBN, издательства и года, проверки отсутствия более нового российского издания и обложки того же издания.
