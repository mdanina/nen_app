# Что почитать с детьми — НЭН

Самостоятельный книжный рекомендательный сервис НЭН. Приложение помогает выбирать книги по возрасту, интересам, настроению и формату чтения.

## Быстрый запуск

```bash
pnpm install
pnpm dev
```

После запуска приложение доступно по адресу `http://localhost:5173`.

Проверки и production-сборка:

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

Подробное описание структуры, каталога и отдельного деплоя находится в [ARCHITECTURE.md](./ARCHITECTURE.md).
