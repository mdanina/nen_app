# Что почитать и посмотреть с ребёнком

Локальный рекомендательный сервис семейного медиа НЭН. Работает на базе 80 произведений из `catalog.json`, без регистрации, бэкенда и внешнего AI API.

## Запуск

```bash
pnpm install
pnpm dev
```

Production-сборка:

```bash
pnpm build
```

Проверки:

```bash
pnpm lint
pnpm typecheck
pnpm test
```

## Возможности

- быстрый подбор по возрасту, формату и интересам;
- самостоятельные каталоги книг, мультфильмов и фильмов;
- разные фильтры и URL-состояние для каждого каталога;
- редакционные подборки и страницы подборок;
- пошаговый умный подбор по правилам НЭН;
- строгие результаты и отдельный блок ближайших совпадений;
- восстановление запроса из URL;
- подробная страница каждого произведения;
- детерминированные типографические обложки;
- локальное избранное через `localStorage`;
- адаптивная вёрстка для мобильных и десктопных экранов.

Основные маршруты: `/books`, `/cartoons`, `/movies`, `/collections`, `/recommend` и соответствующие подробные страницы.
