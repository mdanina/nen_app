# Что почитать с детьми — НЭН

Книжный рекомендательный сервис НЭН: подбор книг по возрасту, интересам,
настроению и формату чтения. Живёт в подкаталоге основного сайта —
`n-e-n.ru/knigi/`.

## Быстрый запуск

```bash
pnpm install
pnpm catalog:build     # собирает каталог, без него приложение пустое
pnpm dev
```

После запуска приложение доступно по адресу `http://localhost:5173/knigi/`.

## Проверки перед PR

```bash
pnpm typecheck
pnpm test              # все наборы: приложение, скрипты импорта, обогащение
pnpm build
```

`pnpm build` пересобирает `data/generated/books.json`. Если после сборки файл
изменился — правку нужно закоммитить, иначе CI не пройдёт.

## Обложки

```bash
pnpm covers:cache      # скачивает обложки в собственный кеш (~70 МБ)
```

Обложки хранятся у нас, а не берутся ссылкой с сайтов издательств: иначе любая
защита от хотлинка обнуляет витрину каталога. Кеш идемпотентен и не коммитится.
Чего в кеше нет — каталог покажет по исходной ссылке.
