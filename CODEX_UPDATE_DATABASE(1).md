# Обновление базы НЭН с 50 до 80 произведений

1. Замените текущий файл `src/data/catalog.json` файлом `catalog_80.json`.
2. Если приложение импортирует JSON под другим именем, сохраните существующий путь и замените только содержимое.
3. Не изменяйте схему фильтров вручную: новые интересы и категории должны вычисляться из данных.
4. Добавлены новые значения:
   - категория: `Классическая книга`;
   - интересы: `наука`, `путешествия`;
   - статусы описания.
5. Проверьте, что:
   - книги категорий `Классическая книга` и `Современная книга` попадают в общий фильтр книг;
   - новые короткие мультфильмы попадают в интервалы до 15 и до 30 минут;
   - поиск находит новые произведения;
   - карточка показывает `shortDescription`;
   - `editorialNote` показывается только когда поле заполнено.
6. Запустите typecheck, tests и production build.
