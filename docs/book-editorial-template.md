# Редакционная карточка книги НЭН v2

## Порядок статусов

`draft` → `facts-review` → `editorial-review` → `rights-review` → `ready` → `published`.

`blocked` используется, когда публикация невозможна до исправления фактов, редакционной разметки или прав.

## Обязательная карточка

### Служебные данные

- Версия схемы: `2`
- ID и стабильный slug
- Статус записи
- Ответственный и проверяющий редакторы
- Дата проверки

### Произведение и издание

- Название и авторы
- Оригинальное название, если подтверждено
- `identificationStatus`: `provisional` или `identified`
- ISBN-13 обязателен только для `identified`
- Издательство, год и страницы указываются только по надёжному источнику
- Ссылки на библиографические источники

### Редакционная разметка

- Возраст от и до
- Формат книги и формат чтения
- Жанры и темы
- Жизненные ситуации
- Подходящие эмоциональные состояния ребёнка
- Эмоциональный тон произведения
- Сложность языка, объём и насыщенность иллюстрациями
- Подходит ли для чтения перед сном

### Редакционные тексты

- Оригинальное короткое описание НЭН
- Оригинальный текст «Почему рекомендуем»
- Тексты нельзя копировать у издательств, магазинов или каталогов

### Безопасность

- Список чувствительных тем может быть пустым
- `sensitiveTopicsReviewed` при публикации всегда должен быть `true`
- Пустой список без отдельного подтверждения проверки публикацию не разрешает

### Обложка

- `placeholder` + `not-required` — безопасное состояние по умолчанию
- `external` + `external-display-only` — временный внешний показ по точному ISBN
- `local` — только при подтверждённой лицензии, открытой лицензии или public domain
- При ошибке изображения интерфейс автоматически показывает фирменную заглушку

## Чек-лист публикации

1. Название и автор подтверждены.
2. Русское издание существует.
3. ISBN не выдуман; при его отсутствии используется `provisional`.
4. Нет дубля по ID, slug, ISBN, нормализованным названию и автору.
5. Все редакционные поля используют утверждённые словари.
6. Описание и причина рекомендации написаны НЭН.
7. Чувствительные темы проверены вручную.
8. Обложка соответствует ISBN или используется заглушка.
9. Запись имеет статус `published`.
10. Генератор, тесты, TypeScript и production build проходят.
