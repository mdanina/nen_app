# Импорт детских книг BnF

Изолированный staging-импорт использует два официальных сервиса Bibliothèque nationale de France:

1. SPARQL `data.bnf.fr` выбирает манифестации с явным `ouvrageJeunesse=true` и связывает их с произведением.
2. SRU Catalogue général возвращает Dublin Core для связанных библиографических ARK.

Единицей staging-каталога является произведение, а не ISBN. Все издания и ISBN сохраняются внутри книги. Дополнительная точная дедупликация выполняется по нормализованным названию и авторам. Не-книжные записи, записи без названия и без автора исключаются.

Аннотации не создаются и не переписываются. Значения `dc:description` сохраняются дословно. Явно технические заметки (`Collection`, штрихкод и подобные) не используются как основное описание. Остальные описания имеют статус `unclassified-bibliographic-description` и требуют редакционной проверки происхождения.

Возраст, настроение, темы НЭН, рекомендации и обложки не импортируются.

Запуск:

```powershell
pnpm import:bnf
```

Результат находится в `data/import/bnf/staging/` и не используется production-генератором книжного приложения.
