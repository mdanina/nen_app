# Обновление книжного каталога

Книжное приложение читает данные из `data/generated/books.json` через репозиторий данных. Файл не связан с React-компонентами: добавление записи не требует изменения интерфейса.

## Текущий процесс

1. Редактор обновляет исходный `data/source/catalog-full.json` или добавляет запись через подготовленный импорт.
2. Выполняется `pnpm catalog:build`.
3. Скрипт выбирает только книги и сказки, проверяет обязательные поля, возраст, повторяющиеся `id` и `slug`.
4. Проверенный снимок записывается в `data/generated/books.json`.
5. Выполняются `pnpm test` и `pnpm build`.

Обязательные поля исходной записи: `id`, `slug`, `title`, `contentType`, `recommendedAgeMin`, `recommendedAgeMax`.

`id` должен быть уникальным. `slug` в исходной записи — служебный: публичный адрес книги собирается из названия на сборке (`scripts/books/public-slug.mjs`), поэтому имя поставщика данных и технические хвосты в URL не попадают. Совпадения разрешаются фамилией автора, затем номером. Что именно переименовалось при последней сборке — в `data/reports/public-slug-rename.json`. Официальный рейтинг указывается только вместе с надежным источником. Неизвестные факты оставляются пустыми.

## Следующий источник данных

Интерфейс работает с `BooksRepository`, поэтому статический JSON можно заменить экспортом Google Sheets, CMS или API. Для редакционного процесса рекомендуется Google Sheets как исходная таблица и автоматическая публикация проверенного JSON-снимка. При росте каталога и команды — headless CMS или база данных с тем же контрактом репозитория.

## Редакционный каталог v2

Новые книги добавляются в `data/source/books-v2.json`. Старый `data/source/catalog-full.json` остаётся неизменным и продолжает поставлять существующие записи. Генератор объединяет оба источника и не допускает дублей по `id`, `slug`, ISBN и нормализованному сочетанию названия с автором.

Новая запись может быть `provisional` без ISBN. Статус `identified` разрешён только с проверенным ISBN-13. В приложение попадают исключительно записи со статусом `published`; `draft`, `blocked` и промежуточные редакционные статусы игнорируются.

Словари находятся в `apps/books/src/domain/books/dictionaries.ts`, формальная схема — в `data/source/books-v2.schema.json`, полный редакционный шаблон и чек-лист — в `docs/book-editorial-template.md`.

Обложка по умолчанию имеет вид `{ "kind": "placeholder", "rightsStatus": "not-required" }`. Временный внешний URL допустим только по точному ISBN и с `external-display-only`. При недоступности изображения интерфейс автоматически возвращается к фирменной заглушке.
